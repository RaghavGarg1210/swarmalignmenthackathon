This folder holds shared working notes created by the team and host-published development scorecards created by the host tool. All four agents can read and write workspace files while they work concurrently. Use the `message` tool for direct coordination: it posts to the shared team feed, and teammates receive the message at the start of their next action. Messages posted during an action appear on a later action. Every `score_dev` call posts a scorecard here and sends a factual notification to the whole team. No signoff or peer approval is needed. Reports to the human operator are private and are not posted here.
